# 💻 Tema 1: Grunnleggende programmering

I tema 1 starter kurset med grunnleggende Python-programmering. Målet er å forstå hvordan programmering fungerer, og hvordan man kan bruke kode til å løse praktiske problemer.

## Nøkkelpunkter

- Variabler
- Betingelser
- Løkker
- Lister, tupler og dictionarys
- Funksjoner
- Moduler og import
- Innebygde funksjoner
- Lambda-funksjoner
- List comprehensions
- Filhåndtering
- Exception handling
- Flask
- HTML
- Flask-app med MySQL
- Objektorientert programmering
  - Klasser
  - Objekter

## Kort forklaring

Python brukes til å lage programmer som kan utføre beregninger, ta imot input fra brukeren og styre programflyt gjennom betingelser og løkker. Etter hvert lærer man å strukturere koden bedre ved hjelp av funksjoner, moduler og biblioteker.

Kurset går også inn på filsystem, feilhåndtering og webutvikling med Flask. Til slutt får studentene en introduksjon til objektorientert programmering, hvor man lærer om klasser og objekter.

# 🌐 Tema 2: Database

Tema 2 handler om databaser, SQL og hvordan man kan modellere og håndtere data på en effektiv og sikker måte.

## Nøkkelpunkter

- Grunnleggende SQL-spørringer
- SELECT, WHERE, ORDER BY, LIKE, IN og BETWEEN
- INSERT, UPDATE og DELETE
- Aggregeringsfunksjoner:
  - COUNT
  - SUM
  - AVG
- GROUP BY
- Datatyper
- CREATE DATABASE
- DROP DATABASE
- ALTER DATABASE
- Primærnøkkel
- Fremmednøkkel
- JOIN
- ER-modell
- Brukeradministrasjon og rettigheter
- Avanserte spørringer
- Subspørringer
- Stored procedures
- Transactions
- Normalisering

## Kort forklaring

Database-delen gir en innføring i hvordan data lagres, struktureres og hentes ut. Studentene lærer å bruke MySQL, Docker og SQL-klienter som MySQL Workbench.

Kurset går fra grunnleggende SQL til mer avanserte spørringer, relasjoner mellom tabeller, datamodellering, sikkerhet og normalisering. Målet er at studentene skal kunne designe og utvikle egne databaser ut fra relevante problemstillinger.



# 🎯 Læringsutbytte


Etter fullført kurs skal kandidaten:

- Ha kunnskap om variabler og funksjoner i grunnleggende programmering.
- Ha kunnskap om integrering av kunstig intelligens og maskinlæring i backend-løsninger.
- Kunne vurdere eget arbeid opp mot gjeldende normer og krav.
- Kunne oppdatere sin yrkesfaglige kunnskap gjennom informasjonsinnhenting og kontakt med fagmiljøet.
- Kjenne til programmeringens historie, tradisjoner og plass i samfunnet.
- Ha innsikt i egne utviklingsmuligheter innen programmering og backend-utvikling.
- Ha kjennskap til minst ett kodeverktøy.
- Kunne gjøre rede for sentrale begreper innen database.
- Ha kjennskap til problemstillinger rundt flere brukere i databaser.
- Ha kjennskap til datamodellering med ER-modeller.
- Ha kjennskap til transaksjoner, samtidighet og robusthet mot feil.
- Ha innsikt i egne utviklingsmuligheter innen databaseløsninger.
- Kunne gjøre rede for bruk av databaser i samfunnet.

## 📌 Kort oppsummert

Dette kurset gir en praktisk innføring i grunnleggende programmering og databaser. Du lærer å skrive Python-kode, bruke funksjoner, håndtere filer, jobbe med Flask og koble applikasjoner til databaser. I database-delen lærer du SQL, datamodellering, relasjoner, normalisering og sikker håndtering av data.

Målet er at du skal kunne utvikle enkle backend-løsninger, forstå hvordan databaser fungerer og kunne bruke programmering til å løse praktiske problemer.
