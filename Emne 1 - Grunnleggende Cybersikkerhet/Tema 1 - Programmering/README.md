## ⚙️ Verktøy og programvare

For å programmere i Python trenger man et kodeverktøy / IDE. Her er to gode alternativer:

### Alternativ 1: Visual Studio Code

**Visual Studio Code** er et lett og fleksibelt kodeverktøy som fungerer på Mac, Windows og Linux. Det kan brukes til Python, webutvikling, databaser og mye mer.

- Download Visual Studio Code – Mac, Linux, Windows
- Installering av kodeverktøy – Visual Code-fil

### Alternativ 2: PyCharm

**PyCharm** er en IDE laget spesielt for Python. Den passer godt for større Python-prosjekter og gir mange innebygde verktøy for utvikling.

- Download PyCharm: The Python IDE for data science and web development by JetBrains
