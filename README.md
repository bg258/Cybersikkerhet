# Cybersikkerhet - Gokstad Akademiet
🏫 Om studiet
 
Cybersikkerhet er en 2-årig fagskoleutdanning på nivå 5.2 i NKR med 120 studiepoeng som gir høyere fagskolegrad. Med denne 2-årige fagskoleutdanningen vil vi tilby studentene en praktisk og teoretisk tilnærming til informasjonssikkerhet, nettverkssikkerhet, og forebygging av cyberangrep. Studiet gir en kunnskap, ferdigheter og generell kompetanse i cybersikkerhet og de sentrale verktøy og teknologier som anvendes i fagfeltet.

 
Bruk av Internett og den teknologiske utviklingen går rasende fort. Teknologi og kommunikasjon flettes stadig tettere sammen. Vi blir alle mer digitale, og trussellandskapet øker i kompleksitet. Cybersikkerhet er et voksende fagfelt som handler om å beskytte digitale systemer, nettverk og data fra ulike trusler.

 
Cybersikkerhet krever forståelse for teknologiens svakheter, samt innsikt i potensielle angripers metoder og motivasjon. For studiet i cybersikkerhet vil det meste av pensum være på engelsk, da mange av ressursene og verktøyene innen faget er engelskspråklige.

 
Bakgrunn: Dagens digitale samfunn etterspør en ny type kompetanse innen IT-sikkerhet. Det er et økende behov for spesialister som kan beskytte organisasjoner mot cybertrusler. Dette studiet er utviklet for å møte denne etterspørselen ved å utstyre den neste generasjonen av cybersikkerhetseksperter med nødvendig kunnskap og ferdigheter.

 
Ansvar- og funksjonsområde: Etter fullført og bestått utdanning kan studentene innta roller innen cybersikkerhet. Med en høyere fagskolegrad innen cybersikkerhet, kan studentene jobbe i IT-avdelinger, sikkerhetsteam, eller som uavhengige konsulenter, blant annet.

 
Studiet er passende for de med interesse for IT, nettverk, og sikkerhet.

 
Tjenesteområde: Studiet danner grunnlag for et bredt spekter av stillinger i private bedrifter og offentlige etater. Kandidaten kan for eksempel jobbe med:
 
* Nettverkssikkerhet 
* Forebygging av cyberangrep
* Incident response
* Sikkerhetsanalyse
* Risikovurdering og -håndtering
* Analyse av nettsted 
* Markedsplaner og strategier
