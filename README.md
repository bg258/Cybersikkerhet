# Cybersikkerhet - Gokstad Akademiet

## 🏫 Om studiet

**Cybersikkerhet** er en 2-årig fagskoleutdanning på nivå **5.2 i NKR** med **120 studiepoeng**, som gir høyere fagskolegrad.

Studiet gir en praktisk og teoretisk tilnærming til:

- Informasjonssikkerhet
- Nettverkssikkerhet
- Forebygging av cyberangrep
- Sikkerhetsanalyse
- Risikovurdering
- Incident response
- Etisk hacking og penetrasjonstesting
- Sikkerhetsarkitektur

Målet med studiet er å gi studenten kunnskap, ferdigheter og generell kompetanse innen cybersikkerhet og sentrale verktøy og teknologier som brukes i fagfeltet.

---

## 🌐 Bakgrunn

Bruk av internett og digitale løsninger utvikler seg raskt. Teknologi og kommunikasjon blir stadig mer integrert i samfunnet, og trussellandskapet blir mer komplekst.

Cybersikkerhet handler om å beskytte digitale systemer, nettverk og data mot ulike trusler. Dette krever forståelse for teknologiens svakheter, samt innsikt i angriperes metoder og motivasjon.

Dagens digitale samfunn har et økende behov for kompetanse innen IT-sikkerhet. Studiet er utviklet for å møte dette behovet og forberede studenter på praktisk arbeid med cybersikkerhet i både privat og offentlig sektor.

---

## 💼 Ansvar- og funksjonsområde

Etter fullført og bestått utdanning kan kandidaten arbeide innen cybersikkerhet, for eksempel i:

- IT-avdelinger
- Sikkerhetsteam
- Konsulentvirksomhet
- Private bedrifter
- Offentlige etater

Studiet passer for personer med interesse for IT, nettverk og sikkerhet.

## 👨‍🏫 Undervisningsform

Undervisningsformen avhenger av hvor og hvordan man studerer. Studiet kan gjennomføres som campusstudium, nettstudium eller nettstudium med fysiske samlinger.

### Campus

Campusundervisning følger et fast timeplanlagt løp med fysisk oppmøte. Undervisningen består av:

- Forelesninger
- Praktiske øvelser
- Gruppearbeid
- Individuell veiledning
- Oppgaveløsing og faglige diskusjoner

Det forventes aktiv deltakelse og jevnt arbeid også utenom undervisningstimene.

### Nett

Nettbasert undervisning gir fleksibilitet i tid og sted. Det gjennomføres ukentlige digitale samlinger, hvor deler av lærestoffet gjennomgås og studentene får veiledning i oppgaver og faglige spørsmål.

Det publiseres også:

- Ukesoppgaver
- Videomateriell
- Faglige artikler
- Relevante ressurser
- Digitale veiledningsmøter

Studenten har ansvar for egen læring og må jobbe strukturert mellom samlingene.

### Nett med fysiske samlinger

Undervisningen foregår hovedsakelig på nett, men med fysiske samlinger omtrent én gang i måneden. Samlingene gjennomføres i Porsgrunn, Stavanger eller Trondheim.

Veiledning er en viktig del av emnet, og det forventes at studenten deltar aktivt for å få best mulig faglig oppfølging.

## 🎯 Overordnet læringsutbytte

### Kunnskaper

Kandidaten:

- Har kunnskap om databasesystemer og digitale teknologier som brukes i cybersikkerhetsarbeid.
- Har kunnskap om HTML og CSS-teknikker som brukes ved programmering og webprosjekter.
- Har kunnskap om IoT og Machine Type Communication.
- Har kunnskap om Enterprise Systems og sikkerhetsarkitektur.
- Kan vurdere eget arbeid i forhold til lovverk, etikk, personvern og GDPR.
- Kan vurdere arbeid med softwaresikkerhet i forhold til etisk hacking og penetrasjonstesting.
- Har kunnskap om cybersikkerhet og kjennskap til IT-bransjen.
- Kan oppdatere sin yrkesfaglige kunnskap om cyberforsvar og sikkerhet.
- Kjenner til IT-bransjens historie og cybersikkerhetens rolle i samfunnet.
- Har innsikt i egne utviklingsmuligheter innen cybersikkerhet.

### Ferdigheter

Kandidaten:

- Kan gjøre rede for faglige valg av databasesystemer og digitale teknologier.
- Kan gjøre rede for valg av HTML- og CSS-teknikker.
- Kan forklare valg knyttet til IoT og Machine Type Communication.
- Kan gjøre rede for valg av Enterprise Systems og sikkerhetsarkitektur.
- Kan reflektere over eget arbeid og justere dette under veiledning.
- Kan finne og vurdere informasjon om cyberforsvar og sikkerhet.
- Kan kartlegge problemer innen softwaresikkerhet og identifisere behov for tiltak.

### Generell kompetanse

Kandidaten:

- Kan planlegge og gjennomføre etisk hacking og penetrasjonstesting alene og i gruppe.
- Kan utføre cybersikkerhetsarbeid etter ulike sektorers behov.
- Kan bygge relasjoner med fagfeller, IT-bransjen og eksterne administratorer.
- Kan delta i faglige diskusjoner om utvikling av cyberforsvar og sikkerhet.
- Kan bidra til organisasjonsutvikling gjennom kunnskap og ferdigheter innen cybersikkerhet.

## 🏁 Mappeeksamen og vurdering

### 📂 Vurderingsform: Mappevurdering

Mappevurdering betyr at studenten vurderes på grunnlag av flere arbeider som samles i en mappe, i stedet for én enkelt eksamen.

Mappevurdering gjelder for:

- Emne 1: Grunnleggende cybersikkerhet
- Emne 2: Operasjonell cybersikkerhet
- Emne 3: Avansert cybersikkerhet

Ved emnestart får studentene utdelt obligatoriske arbeidskrav i form av innleveringer, oppgaver eller andre arbeider. Disse har tydelige vurderingskriterier og innleveringsfrister.

Studenten skal også kunne levere refleksjonsnotat eller oppgave der det begrunnes hva som er inkludert i mappen og hvorfor.

---

## ✅ Vurderingskriterier

Vurderingen baseres på i hvilken grad studenten har:

### Forstått og anvendt fagkunnskap

- Viser forståelse for sentrale begreper, prosesser og verktøy.
- Forklarer relevante teorier og modeller.
- Knytter kunnskap til praktiske og yrkesrelaterte problemstillinger.

### Løst praktiske oppgaver med faglig presisjon

- Bruker relevante metoder og verktøy.
- Viser strukturert problemløsning.
- Begrunner faglige valg.

### Reflektert over egen faglig utøvelse

- Vurderer egne løsninger kritisk.
- Identifiserer styrker og forbedringsområder.
- Justerer arbeidet etter faglige krav og tilbakemeldinger.

### Utviklet relevant og målrettet arbeid

- Leverer i tråd med oppgavens mål.
- Viser forståelse for bruker- og kundebehov.
- Formidler arbeidet strukturert og profesjonelt.

### Fulgt formelle krav og etiske retningslinjer

- Følger retningslinjer for innlevering.
- Tar hensyn til etikk og personvern.
- Bruker kilder korrekt og redelig.

## 🛟 Veiledning og oppfølging

Veiledning og faglig oppfølging skal hjelpe studenten med å oppnå læringsutbyttene i emnet.

Studentene kan få veiledning individuelt eller i gruppe. Veiledningen skal være læringsfremmende og gi studenten mulighet til å forbedre arbeidet før innleveringsfrist.

All veiledning skal være dokumentert, og studenten har selv ansvar for å benytte seg av veiledningstilbudet.

---

## 🚀 Mål med studiet

Målet med studiet er å utdanne kandidater som kan forstå, analysere og håndtere digitale sikkerhetsutfordringer i praksis.

Etter fullført utdanning skal kandidaten kunne bidra til å beskytte digitale systemer, nettverk og data mot cybertrusler, samt arbeide profesjonelt med sikkerhet i ulike virksomheter.
